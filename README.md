# CODATHON-SALES-DATA-ANALYSIS

## Project Overview
An end-to-end Power BI dashboard analyzing 94M Sales, 5.15M Profit, 1K Orders across Products, Categories, Customers and Regions.

**Objective:** To identify the answer for: Are we profitable? What sells most? Who are our best customers and regions?

## Platform used: Power BI

### Phase 1: Data Cleaning using power query
Raw data had quality issues, cleaned before importing to Power BI.

1. **Duplicate Check:** Removed duplicate Driver IDs using Remove Duplicates.
2. **Data Type Fix:** fix date column format to date
3. **Null Handling:** text column fill with unknown and numerical with average and custom column
4. **created new table for east region**
   
**Output:** codathon.xlsx`

### Phase 2: Data Visualization using Power BI

**Data Modeling:**

- Created DAX Measures:
- Created graphs
- Created 3 dynamic dashboards

### Dashboards Created

**1. Sales performance**
**2. Product category analysis**
**3. Customer and regional details**
**4. Insights & Recommendations Page**
- Consolidated findings from all 3 dashboards
